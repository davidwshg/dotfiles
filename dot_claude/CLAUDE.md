# CLAUDE.md (Global)

Global instructions for Claude Code, applied across all projects.

## Git conventions

- Never add an AI/agent co-author trailer (e.g. `Co-Authored-By: Claude ...`) to commit messages.
- All commit messages and PR titles must follow Conventional Commits (https://www.conventionalcommits.org/en/) — e.g. `feat:`, `fix:`, `refactor:`, `chore:`, `docs:`, with an optional scope like `feat(auth):`.
- Never run `git commit` or `git push` unless explicitly requested by the user in that turn.
